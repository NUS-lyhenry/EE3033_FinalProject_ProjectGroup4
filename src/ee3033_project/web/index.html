Reading mapping settings.

Defaults: occupancy threshold 0.10 and minimum pass-through 2. The threshold is the ratio of endpoint hits to ray passes; the pass-through setting controls the minimum evidence count. Lower thresholds preserve thin walls but may retain scattered obstacles. A cell is classified after more than the selected number of ray passes. Edit while stopped, then rebuild the map to use changed settings. Saving does not start mapping.
